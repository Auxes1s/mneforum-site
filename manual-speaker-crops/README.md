# Manual speaker crops

1. Open the original portraits in `input-originals`.
2. Crop each portrait to a perfect square with the face centered and the full hairline visible.
3. Export at 512 x 512 pixels as WebP or high-quality JPEG.
4. Save each finished crop in `output-square` using the exact same base filename.

Expected output names:

- `arsenio-balisacan.webp`
- `christophe-bahuet.webp`
- `roderick-planta.webp`
- `diane-maharjan.webp`
- `vivien-suerte-cortez.webp`
- `joseph-capuno.webp`
- `wilford-wong.webp`

Framing target: head and upper shoulders, a small amount of space above the hair, eyes near the upper third, and no face or hair touching the crop edge.
